This is a plain paragraph. Wrap each paragraph in <p> tags. Paragraphs get space below them automatically.

Use italics for key terms the first time you introduce them, like systolic arrays or arithmetic intensity. Plain links look like this, with a thin underline that brightens on hover.

For important references, such as papers, people or talks, use bold italic links: "A New Golden Age for Computer Architecture". Quotes from a source go in italics: "the next decade will see a Cambrian explosion of novel computer architectures."

A Section Heading

Use <h3> for the main sections of a post. It renders as a small bold italic heading that matches the post title.

A Smaller Label

Use <h4> for subsections. It renders in small spaced capitals.

  • Bulleted lists use <ul> with one <li> per item.
  • Use <ol> instead for a numbered list.
A longer quotation goes in a <blockquote>, set off with a thin rule on the left.

Inline code looks like jax.jit(f). Longer snippets go in a <pre><code> block:

def matmul(a, b):
    return a @ b

Inside code blocks, write < as &lt; and & as &amp;.

An <hr /> draws a faint divider. It's useful before closing notes or references.
